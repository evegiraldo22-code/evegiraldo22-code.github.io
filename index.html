Mi objetivo como QA es encontrar problemas antes de que lleguen al usuario.

Soy QA Tester Junior y QA Engineer en formación, con experiencia práctica en proyectos de testing web y API Testing.

Durante mi formación he diseñado y ejecutado más de 90 casos de prueba, trabajando con análisis de requisitos, pruebas funcionales, pruebas positivas y negativas, clases de equivalencia, valores límite, tablas de decisión, pruebas de API y reporte de defectos.

Me interesa especialmente entender cómo funciona un producto, identificar riesgos y transformar los requisitos en pruebas claras, organizadas y reproducibles.
